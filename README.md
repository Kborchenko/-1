# DIGITAL NETWORK

Многостраничный сайт независимой практики в области подбора персонала и маркетингового консалтинга.

## Состав

- 11 HTML-страниц, включая страницы услуг, кейсов, контактов и юридические документы;
- адаптивные стили, анимации и интерактивная 3D-сцена на Canvas;
- оригинальные изображения кейсов и портреты для демонстрационного раздела отзывов;
- favicon для вкладки браузера;
- `.htaccess`, `robots.txt` и инструкция `HOSTING.txt`.

Откройте `index.html` для локального просмотра. Для публикации загрузите всё содержимое этой папки в корень сайта на хостинге.

Форма работает на стороне браузера: проверяет поля и показывает состояние успешного заполнения. Для доставки заявок необходимо подключить обработчик формы.
